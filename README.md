# My-Floor-My-Design-


A powerful, browser-based floor plan designer that allows you to create detailed layouts for homes, kitchens, restaurants, and commercial spaces.

![Floor Plan Designer](https://img.shields.io/badge/Version-2.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## Features

### 🏠 Multi-Category Item Library
- **Furniture**: Chairs, tables, sofas, beds, doors, windows, plants, bookshelves, desks
- **Kitchen Appliances**: Stove, refrigerator, sink, oven, microwave, dishwasher, cabinets, counters, toaster, blender
- **Restaurant Equipment**: Bar counter, barstools, cash register, host stand, wait station, commercial fridge, grill, fryer, prep station, display case

### 🛠️ Powerful Design Tools
- **Select/Move Tool**: Click and drag to move items around your layout
- **Wall Drawing Tool**: Create walls and partitions with precise straight lines
- **Rotation Tool**: Rotate items to any angle with snapping options
- **Grid System**: Toggleable grid with snap-to-grid functionality for precise placement

### 💾 Project Management
- **Save/Load**: Store your designs in browser localStorage
- **Import/Export**: Export designs as JSON files or PNG images
- **Undo/Redo**: Full history support with unlimited undo/redo actions
- **New/Clear**: Start fresh or clear your current canvas

## Quick Start

1. **Open the Application**: Simply open `index.html` in any modern web browser
2. **Choose Your Tools**: Select from the toolbar on the left
3. **Add Items**: Click on items from the palette or use the place item tool
4. **Customize**: Move, rotate, and arrange items to create your perfect layout
5. **Save Your Work**: Use the save button to store your design locally

## Usage Examples

### Designing a Home
1. Use the wall tool to outline rooms
2. Add doors and windows
3. Place furniture like beds, sofas, and tables
4. Add decorative elements like plants

### Planning a Kitchen
1. Create your kitchen layout with walls
2. Add major appliances (refrigerator, stove, oven)
3. Place counters and cabinets
4. Add smaller appliances (microwave, toaster, blender)

### Setting Up a Restaurant
1. Design the dining area with tables and chairs
2. Create the kitchen space with commercial equipment
3. Add service areas (bar, host stand, wait stations)
4. Include storage with commercial refrigerators

## Keyboard Shortcuts

- `Delete` or `Backspace`: Remove selected item
- `R`: Rotate selected item 45 degrees
- `Ctrl+Z`: Undo last action
- `Ctrl+Y`: Redo last action
